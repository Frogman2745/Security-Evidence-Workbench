# Data provenance

`cisa_kev.json` is a snapshot of CISA's public KEV feed downloaded on 2026-11-08. It is evidence of the feed's contents at that time, not a continuously current catalog. Run a new ingestion before making current-priority claims. `synthetic_assets.csv` contains four fictional assets, and `review_candidates.csv` contains seven product-name matches that still require version and configuration review. `reviews.sqlite3` is local reviewer state and is excluded from Git and the portfolio ZIP.
